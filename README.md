C++ ဟာ ပေါ့ပါးမြန်ဆန်တဲ့ Programming Language တစ်ခုဖြစ်တာကြောင့် high ဖြစ်တဲ့ Hardware Specification တွေ မလိုပါဘူး။ အခြေခံ OS နဲ့ Computer တိုင်းလိုလိုမှာ အဆင်ပြေစွာ စတင်နိုင်ပါတယ်။

# Learning C++
==============

This repository is created both for my personal review and practice of C++ programming language, as well as a useful learning resource for anyone interested in learning C++ from scratch. I hope this repository proves helpful to both myself and fellow learners.

---

## 💻 Hardware Requirements to Start C++

Since C++ is a lightweight and high-performance programming language, it does not require high-end hardware specifications. You can smoothly get started on almost any standard computer or operating system.

* **Operating System:** Windows 7/10/11, macOS, Linux
* **Processor (CPU):** Intel / AMD 1.5 GHz Dual-Core or higher
* **RAM:** Minimum 2 GB (4 GB or 8 GB recommended for smoother performance)
* **Storage Space:** Minimum 128 GB to 256 GB

---

## 🛠️ Text Editors & IDEs for C++

### 1. Visual Studio Code (VS Code)
* **OS Support:** Windows, macOS, Linux

### 2. Code::Blocks
* **OS Support:** Windows, macOS, Linux

### 3. Dev-C++
* **OS Support:** Windows Only

### 4. Visual Studio (Community Edition)
* **OS Support:** Windows Only

### 5. Xcode
* **OS Support:** macOS Only

---

## ⚙️ Compilers
* **Windows:** MinGW-w64 (GCC) or MSVC (Microsoft Visual C++)
